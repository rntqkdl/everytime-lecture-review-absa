# 연구 계획 요약

## 연구 질문
1. 학생들이 강의를 좋게 평가할 때 반복적으로 언급하는 요인은 무엇인가?
2. 학생들이 강의를 나쁘게 평가할 때 반복적으로 언급하는 요인은 무엇인가?
3. 하나의 강의평 안에서 긍정과 부정이 함께 나타나는 경우는 어떤 패턴인가?
4. 별점이 높은 리뷰 안에서도 반복적으로 등장하는 불만 요인은 무엇인가?
5. 별점이 낮은 리뷰 안에서도 긍정적으로 언급되는 요인은 무엇인가?

## 분석 전략
- 원본 강의명을 `course_group`으로 정규화해 글쓰기와 실용영어를 분리 비교한다.
- 리뷰를 문장/절 단위 `segment`로 나누어 aspect와 sentiment를 세밀하게 본다.
- 별점은 `rating_satisfaction_signal`로만 변환하고 감정 라벨로 사용하지 않는다.
- 최종 aspect discovery는 Colab T4에서 SentenceTransformer 임베딩과 UMAP/HDBSCAN cluster를 사용한다.
- 로컬 CPU baseline은 결과 구조 검증과 Colab 전 준비 용도로만 사용한다.

## 기대 산출물
- 강의군별 리뷰 수, 세그먼트 수, 별점 만족도 신호 분포
- 자동 발견 aspect cluster와 대표 세그먼트
- aspect별 긍정/중립/부정 비율
- 높은 별점 리뷰 안의 부정 segment
- 낮은 별점 리뷰 안의 긍정 segment
- 좋은 강의 요인과 불만 요인 요약
